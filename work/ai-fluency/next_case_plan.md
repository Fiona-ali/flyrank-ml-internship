## Three-beat case shape

- **Problem:** Editors need a practical way to prioritize which eligible pages to inspect for a possible refresh.
- **What I did:** Built a reproducible logistic-regression ranking and compared it with the Week-4 rule on a fixed client-held-out split of the anonymized repository starter extract.
- **What came of it:** The model reached 0.72 Precision@50 versus 0.38 for the rule on that split. The target is a trailing-window proxy, so the result supports human review only and does not establish future performance or refresh impact.
